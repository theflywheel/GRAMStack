## SakhiCredit

SakhiCredit demonstrates application sign-in, an exact sharing request, registry ownership verification, explicit consent, scoped retrieval and the durable audit trail.

[Explore SakhiCredit](/demos/sakhicredit) · [Open the live application](https://sakhicredit-b9b69819.up.railway.app/) · [Watch the recorded walkthrough](/demos/sakhicredit/walkthrough)

The demo uses fictional identities and source records. Read [capabilities and limitations](/demos/sakhicredit/capabilities) before interpreting it as a production registry integration.
