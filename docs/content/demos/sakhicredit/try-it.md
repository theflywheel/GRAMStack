title: Try the live application
---

[Open SakhiCredit](https://sakhicredit-b9b69819.up.railway.app/).

1. Choose **Sign in with GRAMStack**. In eSignet, select UIN/VID, enter fictional Sunita ID `9000000001`, and use demo OTP `111111`.
2. Start an application using `member-12345`. Choose membership status, optionally including savings summary.
3. Open **Review sharing request**. Complete the separate person sign-in and registry verification, then inspect the exact notice.
4. Approve or decline the request. Return to SakhiCredit; after approval, choose **Get approved details**.
5. Follow **View access audit in consent history** to inspect who accessed which fields and when. A fresh history session may require sign-in again.
6. Sign out to invalidate the product session.

Use a new request to test a different scope. A used approval cannot authorize another retrieval. A DeDi commitment can appear after the receipt because anchoring is asynchronous.

No real credentials or personal records are needed. [Demo boundaries](/demos/sakhicredit/capabilities) · [Recorded walkthrough](/demos/sakhicredit/walkthrough)
