GRAMStack architecture and data flow

Follow a SakhiCredit request from sign-in and consent to retrieval and audit. Play the sequence or select a numbered connection to see the request, participants, and state. Select a component to highlight its incoming and outgoing connections. Scroll the diagram horizontally on smaller screens.

Lifecycle states come from specs/0.3.0/lifecycle.json. Other end states: REJECTED, DENIED, WITHDRAWN, EXPIRED, CANCELLED, FAILED, DELIVERY_UNKNOWN. Dashed grey lines show which component writes to which database. All identities and records in the demo are fictional.
